# Módulo 08 — Interface e Configurações

## Finalidade

Expor ao operador os controles e estados necessários para acompanhar e comandar o sistema.

## Informações importantes

- fonte de grade em uso;
- status Cultura;
- próximo evento;
- countdown;
- estado CasparCG;
- estado ATEM;
- fonte PROGRAM atual;
- estado PGM;
- estado Logo MP1;
- logs principais;
- modo AUTO/MANUAL quando aplicável.

## Horários

O editor de horário com campos independentes HH / MM / SS foi aprovado operacionalmente e não deve ser revertido.

## Persistência

Configurações operacionais precisam sobreviver ao reinício do Scheduler.

## Princípio

A interface não deve esconder qual fonte ou regra está comandando o sistema.

## Estado

**OPERACIONAL / EM EVOLUÇÃO**.
